## How to Contribute

We welcome contributions from enterprise and sovereign cloud developers. This project has diverged significantly from upstream CIPP, so please do not assume that upstream contribution guides apply here.

* Open an issue to discuss larger changes before starting work.
* Keep pull requests focused, and describe what changed and why.
* Do not include customer data, credentials, tokens or secrets in code, tests, issues or logs.
* Changes to code inherited from upstream should be kept small and clearly marked, so that they remain easy to review.

For security vulnerabilities, do not open a public issue: follow [SECURITY.md](SECURITY.md).
